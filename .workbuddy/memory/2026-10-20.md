### HTTPS 推送失败，SSH 可用
- 症状：`git push` 报 `schannel: server closed abruptly` 与
  `CONNECT tunnel failed, response 502`
- 根因：系统设了 `http_proxy=http://127.0.0.1:2026`，该本地代理不通 GitHub；
  git 自身没配代理，完全依赖环境变量
- 解法：绕开代理走 SSH（`~/.ssh/id_ed25519` 已绑定 GitHub 账号
  hongligongsi）：

```bash
timeout 120 env -u http_proxy -u https_proxy -u HTTP_PROXY -u HTTPS_PROXY \
  git push git@github.com:hongligongsi/qingwa-openpnp-hongli.git hongli:hongli
```

- 验证同理，`git fetch` 走 HTTPS 也会失败，改用
  `git ls-remote git@github.com:...` 查真实远程 HEAD
- 注意：HTTPS fetch 失败后，本地 `origin/hongli` 引用仍是旧的，
  不能据此判断推送是否成功
