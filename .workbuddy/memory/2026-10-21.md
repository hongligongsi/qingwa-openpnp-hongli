- 用户问「如果改固件怎么改」，核实并写入 README 新小节「🎛 常用调整速查 → 四、直接改固件（编译期）」：
  1) **关键发现**：machine.xml 的 `MOVE_TO_COMMAND` = `{Acceleration:M204 S%.0f }` +
     `G1 ... {FeedRate:F%.0f}` → OpenPnP **每次移动前都下发 M204 S<加速度>**，
     `HOME_COMMAND` 里也有 `M204 S%.2f`。所以固件的 `DEFAULT_ACCELERATION`(2000) /
     `DEFAULT_TRAVEL_ACCELERATION`(2500) 会被覆盖，改它们只在脱机时有效
  2) 固件真正有意义的场景：改**安全上限**（DEFAULT_MAX_FEEDRATE 1363 /
     DEFAULT_MAX_ACCELERATION 1377）、固件独有的微步/归位/行程、脱机运行、开 EEPROM_SETTINGS
  3) 电流行号：X_CURRENT 2850 / Y 2870 / Z 2890 / I 2930 / J 2940；
     **Y2_CURRENT 直接等于 Y_CURRENT，改 Y 即同时改双 Y**
  4) 灯亮度：`NEOPIXEL_BRIGHTNESS` 3758、`NEOPIXEL2_BRIGHTNESS` 3765（均为初始值 255）、
     `NEOPIXEL_STARTUP_TEST` 3759。但 OpenPnP 点灯必发 `M150 P255`，固件初值会被覆盖
  5) 改配置四条固定流程：cp 到 rev5-config → check-config-i18n.py →
     check-config-code-intact.py（可选）→ `pio run -e Opulo_Lumen_REV5 -t upload`
     只编译 `pio run -e Opulo_Lumen_REV5`；产物 .pio/build/Opulo_Lumen_REV5/firmware.bin
  6) 铁律：只改数字别动结构 / 改微步必须同步改 steps-per-unit（64→32 则 320→160）/
     电流一次加 100mA，别超 1200mA
