hongli pnp 安装版 安装说明
========================================

一、安装包信息
- 文件名：honglipnp-1.0.exe（以实际发放的安装包文件名为准）
- 大小：约 230 MB
- 特点：自带 Java 17 运行环境，无需单独安装 Java
- 本版本包含定制内容：全中文界面、问题&解决方案条目级中文翻译（11 个数据文件）、
  飞达类型中文名、总览页（进度曲线 / 环形进度 / 底视快照画廊）、
  拼板阵列即时刷新、一键校正（视觉 + 皮带间隙 + 偏移标定）、
  贴完 / 异常 / 重复贴片三类指令、同拍（并行底视）等；
  完整需求清单见仓库文档《hongli pnp 定制需求规格》
  （docs/hongli-pnp-需求规格.md）
- 本说明按《hongli pnp 定制需求规格》口径编写（配置目录 .hlpnp、
  安装位置 C:\honglipnp）；早期 lfpnp v1.0 使用旧路径，不再维护

二、系统要求
- Windows 10 / 11 64 位
- 按当前用户安装，无需管理员权限

三、安装步骤
1. 双击 honglipnp-1.0.exe。
2. 若弹出「Windows 已保护你的电脑」蓝色提示（安装包未做数字签名，
   属正常现象）：点击「更多信息」→「仍要运行」。
3. 按安装向导提示点击「安装」，等待完成（约 1~2 分钟）。
4. 安装位置：C:\honglipnp
5. 安装完成后，开始菜单生成「hongli pnp」文件夹及快捷方式，点击即可启动。

四、静默安装（可选，适合批量部署）
在命令行中执行：
    honglipnp-1.0.exe /quiet
安装过程无任何界面提示，完成后直接在开始菜单查找 hongli pnp。

五、配置文件说明
- 机器配置（machine.xml、packages.xml、作业文件等）保存在：
  C:\Users\<用户名>\.hlpnp
- 定制版使用独立配置目录 .hlpnp，与原版 OpenPnP 的 .openpnp2 互不干扰，
  可与原版共存于同一台电脑。
- 安装版与绿色版（honglipnp\OpenPnP\OpenPnP.exe）共用同一 .hlpnp 配置目录，
  配置互相兼容。
- 覆盖安装、升级重装不会丢失配置。
- 如需彻底重置为出厂状态，先备份后删除 .hlpnp 文件夹，
  下次启动会自动重新生成默认配置。

六、卸载
- 打开「设置」→「应用」→「安装的应用」，找到 hongli pnp 点击卸载；
- 卸载不会删除 .hlpnp 配置目录，如需一并清理请手动删除。

七、常见问题
1. 启动后较长时间无响应：首次启动需加载配置与相机驱动，
   正常约 15~20 秒，请耐心等待。
2. 双击无反应：确认文件完整（大小约 230MB），必要时重新复制安装包。
3. 相机/串口无法打开：安装版与绿色版不要同时运行，
   两者会争用相同的相机与串口资源；先关闭另一个实例再启动。
4. 桌面没有快捷方式：本版本默认只在开始菜单创建快捷方式，
   可自行右键「hongli pnp.lnk」发送到桌面快捷方式。
