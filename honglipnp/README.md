8# hongli pnp

> 基于 OpenPnP 深度定制的桌面式贴片机控制软件 · Windows x64 · 全中文界面

本文是 hongli pnp 的**定制功能清单**（需求口径），描述产品应具备的能力，
不等同于当前构建产物的实现状态。完整需求规格与实现状态对照见
`docs/hongli-pnp-需求规格.md`。

定制方向集中在四件事：重构操作界面、把问题提示与术语中文化到可用粒度、
隔离配置以避免与原版冲突，并针对产线场景扩展同拍（并行底视）、定制飞达、
G-code 外设联动与校正流程。

它**不是**原版 OpenPnP 的一个皮肤或插件，而是一份独立的深度定制发行版——
与原版可以安装在同一台电脑上，配置互不干扰。

## 一、当前交付物

本目录下是一份 **jpackage 打包产出的运行时映像**（绿色，解压即用）：

| 路径 | 说明 |
| --- | --- |
| `OpenPnP/OpenPnP.exe` | 主程序启动器 |
| `OpenPnP/app/` | 应用本体：`openpnp-gui` 主 jar + `lib/` 下 97 个依赖 jar |
| `OpenPnP/runtime/` | **自带精简版 Java 17.0.20.1 运行环境**，无需事先安装 JDK/JRE |
| `安装说明.txt` | 安装、静默安装、配置目录、卸载与常见问题 |

对外发放的 Windows 安装版由 **jpackage + WiX** 进一步包装为单个 `.exe` 安装程序，
默认安装到 `C:\honglipnp`，支持 `/quiet` 静默安装，适合批量部署。

## 二、定制功能清单

### 界面重构
仿 smtez 风格的整体重做，目标是「信息密度高、操作步骤短」：

- **无边框自绘窗口**——去掉操作系统标题栏，界面自主绘制
- **药丸操作条**——常用动作收拢为圆角胶囊按钮组
- **总览页**——进度曲线 + 环形进度 + 底视快照画廊三个模块同屏呈现生产状态
- **隐藏标签页**——低频配置项按需展开，默认视图更干净
- **全局自绘滑块 `ThickSliderUI`**——统一的加粗手感滑块，替换 Swing 原生控件

### 中文化
- 默认以**简体中文**启动
- **问题条目级翻译**：覆盖 `issues_zh_CN` 下 11 个数据文件
  （actuator / axis / calibration / camera / gcode / head / kinematic /
  misc / nozzletip / scripting / vision），把 OpenPnP 的「问题与解决方案」
  逐条译为中文
- 视觉流水线、飞达类型、各类下拉枚举统一中文显示

### 配置隔离
- 使用**独立配置目录 `.hlpnp`**（machine.xml、packages.xml、作业文件等均在此）
- 与原版 OpenPnP 的 `.openpnp2` **共存互不干扰**，同一台机器可同时安装两版
- G-code 等扩展项全部持久化，**向下兼容旧配置**，升级后老配置照常可用

### 任务页增强
- **单板表格精简列**——只保留作业真正需要的字段
- **Mark 点独立开关**——Mark  fiducial 不再与拼板开关捆绑
- **拼板阵列**——带防抖重建，调整阵列参数时不会卡顿或反复重建
- **一键校正**——串起视觉校正、皮带间隙补偿、偏移量标定三步

### 视觉增强
- **识别模式预设**——常用参数组合一键套用
- **识别区大小滑块**——拖动即可调整 ROI 尺寸
- **零件厚度补偿开关**
- **「移到底部拍照位置」**——快速把头移到底视相机上方
- **流水线 XML UTF-8 乱码修复**——解决中文路径/注释导致的解析乱码

### 同拍功能
- 多吸嘴**并行底视拍照**（`ReferenceSimultaneousVision`），显著压缩取料循环时间
- **条件不满足时自动回退**为顺序拍照，不牺牲稳定性

### 定制飞达
- **AS2 自动飞达**（`As2Feeder`）——自动完成 GcodeDriver 配置与执行器挂载，免去手工接线映射
- **蝌蚪飞达**——免通讯，接上即用

### G-code 扩展
- 新增三类指令：**贴完**、**异常**、**重复贴片**，便于与外围设备（点胶、AOI、报警器）联动
- 全部持久化，兼容旧配置

### 打包交付
- jpackage + WiX 打包为 Windows 安装 exe
- 默认安装到 `C:\honglipnp`
- 支持静默安装

## 四、使用

安装与部署步骤见 **`安装说明.txt`**。

首次启动需加载配置与相机驱动，约 15~20 秒属正常现象。
安装版与绿色版共用同一份配置，但**不要同时运行**，两者会争用相机与串口资源。
