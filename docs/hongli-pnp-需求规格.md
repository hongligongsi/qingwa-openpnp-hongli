---

## 一、目标与范围

在 OpenPnP 基线上，针对桌面式贴片机的实际产线使用场景，做一次系统性的
定制改造，覆盖四件事：

1. **操作效率**——重构界面，缩短常用动作路径，突出生产过程中的关键信息
2. **本地化**——把 OpenPnP 的问题提示与术语真正中文化到"可读可用"的粒度
3. **产线可靠性**——配置隔离、校正流程、同拍提效、G-code 外设联动
4. **可交付性**——打包成开箱即用的 Windows 安装程序，兼容旧配置

**非目标**：不改动运动控制算法与视觉算法本身的精度/策略；不做跨平台适配。

### R1 界面重构

仿 smtez 风格的整体界面重做，目标是信息密度高、常用动作步骤短。

| 编号 | 需求 | 验收标准 | 优先级 |
| --- | --- | --- | --- |
| R1.1 | 无边框自绘窗口 | 窗口不显示操作系统标题栏，拖动、最大化、关闭均由自绘区域响应 | P1 |
| R1.2 | 药丸操作条 | 常用动作收拢为圆角胶囊按钮组，可在主界面一键触达 | P1 |
| R1.3 | 总览页 | 同屏呈现三模块：**进度曲线**、**环形进度**、**底视快照画廊** | P1 |
| R1.4 | 隐藏标签页 | 低频配置项默认隐藏、按需展开，主视图不被无关标签占满 | P2 |
| R1.5 | 全局自绘滑块 `ThickSliderUI` | 全局统一加粗手感滑块，替换 Swing 原生 JSlider，所有滑块一致 | P2 |

**R1.3 明细**
- 进度曲线：随生产实时绘制，能反映批次进度趋势
- 环形进度：当前作业完成百分比
- 底视快照画廊：最近吸嘴取料的底视图像缩略图，可追溯单颗状态

## 三、横向约束

- **向下兼容**：所有配置相关的新增能力（R3、R8）必须能加载旧配置
- **稳定性**：同拍回退、拼板重建等过程不能出现死机/卡死
- **可共存**：与原版 OpenPnP 同机安装、同时在盘，互不干扰（但不可同时运行，会争用相机/串口）
- **免安装 Java**：交付物自带精简版 JRE，最终用户无需安装 Java
