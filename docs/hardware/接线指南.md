# 主板接线指南

> 依据：`docs/hardware/SCH_插板_主板电路图.pdf`（嘉立创EDA V1.0）+ 固件 `pins_OPULO_LUMEN_REV5.h` + `.openpnp2/machine.xml`
> 所有针序均已逐脚目视核实；`●1` 表示座子上靠近白色圆点标记的那一针。

## 一、先接电源（最容易烧，务必先看）

**U21 · 24V 电源输入（KF128-5.08 绿色接线端子，2P）**

| 端子 | 接什么 |
|------|--------|
| 1 | GND（电源负极） |
| 2 | +24V（进板后先过 7A 保险丝 F2） |

- 用 **24V 开关电源**，建议 ≥150W（六轴电机 + 灯带 + 真空泵同时在跑）。
- **上电前先用万用表确认极性**——接反没有防反接保护。
- 板上自带两级降压：24V→5V（主电）、24V→5V-II（灯带/外设），都不用你操心。
- USB 方口（USB2）只做通信；旁边 H5 三脚跳线可在「USB 供电 / 板载 5V」之间选择（默认不用动，D25 二极管已防倒灌）。

## 二、步进电机（6 个白色 XH2.54-4P 座）

所有电机座针序**完全相同**：

| 针 | 信号 | 说明 |
|----|------|------|
| ●1 | M1B | ┐ |
| 2 | M1A | ┘ 第一组线圈 |
| 3 | M2A | ┐ |
| 4 | M2B | ┘ 第二组线圈 |

**怎么分线圈**：42 步进电机 4 根线里，用万用表通断档测——**相通的两根是一组线圈**。一组接 1/2，另一组接 3/4。如果接反了电机只会抖动不转，把任意一组两根线对调即可（不会烧东西，放心试）。

| 板上丝印 | 座号 | 固件轴 | OpenPnP 轴 | 驱动机构 |
|----------|------|--------|-----------|----------|
| X | CN29 | X | X | 龙门左右 |
| Y1 | CN30 | Y | Y | 前后 · Y 主电机 |
| Y2 | CN34 | Y2 | （随 Y 同步） | 前后 · Y 副电机 |
| Z | CN32 | Z | Z | 机头升降 |
| L | CN33 | I | A（N1 旋转） | 左吸嘴旋转 |
| R | CN31 | J | B（N2 旋转） | 右吸嘴旋转 |

- Y1 与 Y2 必须接**同型号电机**，两根同步带才不会较劲。
- 旋转轴 L/R 对应 OpenPnP 里的 A/B 轴（吸嘴自转）。
- 电机电流在固件 `Configuration_adv.h`（X/Y=800/1000 mA…）或运行时 `M906` 调，详见 README「调参速查」。

## 三、限位开关

**CN25 · XY 限位（XH2.54-4P）**

| 针 | 信号 |
|----|------|
| ●1 | GND |
| 2 | X_MIN（X 限位信号） |
| 3 | Y_MIN（Y 限位信号） |
| 4 | 3V3 |

**U23 · Z 限位 + 备用（XH2.54-5P）**

| 针 | 信号 |
|----|------|
| ●1 | 3V3 |
| 2 | 5V-II |
| 3 | GND |
| 4 | Z_MIN（Z 限位信号） |
| 5 | AUX（备用 IO，PD13） |

- 三根限位都是 **3 线接法：信号 + GND + 3V3**，板上已有 10 kΩ 上拉 + 100 nF 滤波。
- 用**常开（NO）**开关：触发时信号脚碰到 GND。光耦/机械开关都可以；若用光电开关注意供电脚接 4 针的 3V3。
- 位置对应：X 限位在龙门左端、Y 限位在后端、Z 限位在机头最高点，和 OpenPnP 里 homing 方向保持一致。

## 四、MOS 输出 ×4（真空泵 / 电磁阀都接这里）

4 个 XH2.54-2P 座，针序相同：**●1 = +24V（常供）、2 = 开关输出（低边 NMOS）**

| 座号 | 板上网络 | 固件 | 控制命令 | 建议用途 |
|------|----------|------|----------|----------|
| CN24 | MOS-1（PB8） | FAN0 | `M106 P0 S0-255` | 顶面真空泵 |
| CN23 | MOS-2（PB9） | FAN1 | `M106 P1 S0-255` | 底面真空泵 |
| CN22 | MOS-3（PE5） | FAN2 | `M106 P2 S0-255` | 贴装电磁阀 |
| CN21 | MOS-4（PE6） | FAN3 | `M106 P3 S0-255` | 备用 |

接法：**24V 负载的正极 → 座子 1 针（+24V），负极 → 座子 2 针（开关输出）**。
板上有 SS510 续流二极管，直接接感性负载（泵、电磁阀）没问题。这 4 路在 OpenPnP 里配置成 GcodeDriver 的 `M106 P0..P3` 即可控制真空。

## 五、灯带（WS2812，XH2.54-3P ×2）

| 座号 | 用途 | 针序 |
|------|------|------|
| CN28 | 顶灯 TOP-LIGHT | ●1=GND，2=5V-II，3=数据（← PC8） |
| CN27 | 底灯 BTM-LIGHT | ●1=GND，2=5V-II，3=数据（← PC7） |

- 板上已经做好 3.3V→5V 电平转换（74LVC2G34），灯带数据线**直接接 3 针**，不用自己加转换。
- 灯带是「进线」接座子：5V→2 针、GND→1 针、DI→3 针；再从灯带末端出线接下一段。
- 控制：`M150`（顶灯加 `S1`），亮度 `M150 P0-255`，详见 README 环形灯章节。

## 六、风扇

**CN20 · 控制器风扇（XH2.54-2P）**：●1=+24V，2=开关输出。
固件自动控制（任一电机使能就转，停机 120 s 后停），不需要 OpenPnP 干预。接个 24V 风扇给驱动芯片散热即可。

## 七、RS485 智能飞达总线

**CN26 · FEEDERS（XH2.54-4P）**：●1=RS485−，2=RS485+，3=+24V，4=GND。

- 给支持 RS485 的智能飞达（如 LumenPnP Flock/ FrogFeeder）供电 + 通信，A/B 两根线可以菊花链多台。
- 板上收发器是 MAX3078，挂固件 USART1（PA9/PA10）。
- ⚠️ **当前固件尚未启用 RS485 通信功能**，硬件已就绪，协议需要二次开发；现在飞达走各自舵机/电机方案的先不用接这路。

## 八、不用接线的部分（心中有数即可）

| 部件 | 说明 |
|------|------|
| 真空压力传感器 ×2 | 板载 XGZP6857D，走 I2C（PCA9545A 复用），只需接**气管**，无电线 |
| 蜂鸣器 | 板载 2.7 kHz 有源贴片，`M300` 发声 |
| 板版本识别 ID0–ID3 | 出厂 0Ω 电阻已定，别动 |
| T9 跳线 | CHIMERA 吸嘴头检测（PC1），接专用检测头才短接 |
| T11 跳线 | USB 屏蔽层接地选择，默认不动 |

## 九、扩展 / 调试座（以后玩扩展用）

| 座子 | 规格 | 内容 |
|------|------|------|
| U30 · AUX | 2×4（2.54） | 3V3 / GND / PA5(PWM1) / PA6(PWM2) / PA15(PWM3) / PC0(模拟A1) / PB6(SCL) / PB7(SDA) |
| H6 · SWD | 2×5（2.54） | 3V3、REST、SWDIO(PA13=IO72)、SWCLK(PA14=IO76)、GND —— ST-Link 烧录/调试就接这里 |
| U24 | XH2.54-6P | 5V-II / GND / GND / BOOT0 / REST / 预留 —— 串口 ISP 刷机用（BOOT0 拉高 + REST 复位进 bootloader） |

> ⚠️ PA13/PA14 同时被引到 H6 和 U24 相关网络（丝印 IO72/IO76），外接时别和 SWD 调试冲突。

## 十、上电检查顺序（建议）

1. 只接 24V 电源，不接电机 → 看电源灯、量 U21 端子电压（应 24V）。
2. 接 USB，上位机连上后发 `M115` 确认通信。
3. 发 `M119` 看三个限位状态（应全为 open，用手按一下变 TRIGGERED）。
4. 低速点动各轴（OpenPnP「机器控制」面板），核对**方向**——X 往右、Y 往后、Z 往上，反了就改 OpenPnP 里该轴的 Direction，或对调该电机一组线圈。
5. 逐一发 `M106 P0 S255`…`P3` 确认四路 MOS 输出动作，再接真空泵/电磁阀。
6. 最后接灯带，`M150 R255 G0 B0` 应全亮红色。
