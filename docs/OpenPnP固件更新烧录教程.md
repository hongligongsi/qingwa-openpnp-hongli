## 准备工作

短接这两个跳线触点，24V / 5V / 3V3 指示灯应点亮。

## 将主板启动到 DFU 模式

方法一：

1. USB 线保持插在电脑上，用数据线将青蛙主板连接到您的计算机。
2. **按住 BOOT 按键不放**（一直按着不要松手）。
3. 按一下 RST 复位键，然后松开 RST。
4. **继续按住 BOOT，再多等 1 秒**，再松开 BOOT。
5. 松开之后，立刻看 Windows【设备管理器】：
   - 正常情况：会出现 `STM32 BOOTLOADER`。

方法二（官方口诀）：

1. 按住 BOOT 按钮（不要松开）。
2. 按住 Reset 按钮并等待 10 秒钟。
3. 松开 Reset 按钮并等待 10 秒钟。
4. 松开 BOOT 按钮。

> **进不去 DFU 模式怎么办？**
>
> - 如果您很难让板子进入 DFU 模式，请尝试拔下 USB 和电源插孔，然后按住"BOOT"按钮，再插入 USB 和电源插孔，等待 10 秒，然后松开 BOOT 按钮。
> - 如果您使用的是 Windows，请尝试卸载 STM32CubeProgrammer 并重新安装。这也将重新安装可以修复连接问题的 USB 驱动程序。
> - 你也可以在设备管理器中查看有没有 STM32 DFU 设备来判断是否链接成功。

## 用 STM32CubeProgrammer 刷写固件

### 连接主板

1. 打开 STM32CubeProgrammer。
2. 从右侧的连接类型下拉列表中选择 **USB**。
3. 单击 Port 行中的刷新按钮以检测主板的端口。
4. 从 Port 下拉菜单中选择新发现的 USB 端口。
5. 仔细检查右侧的其他字段是否与下表匹配：

| 参数 | 值 |
|---|---|
| PID | `0xdf11` |
| VID | `0x0483` |
| Read Unprotect (MCU) | 不勾选 |
| TZEN Regression (MCU) | 不勾选 |

6. 点击 Connect 绿色按钮连接到主板。

### 全片擦除

通过单击 "Full Chip Erase" 按钮删除芯片上的所有闪存。

> 擦除芯片上的所有闪存需要几分钟。请等待，直到您看到一个确认弹出窗口，表明该过程已完成，然后再继续。

### 烧录固件

1. 单击 Browse 按钮并选择您之前下载的固件映像。
2. 单击 Start Programming 按钮将固件上传到主板。
3. 等待确认弹出窗口出现，表明该过程已完成。

## 刷写完成后

按下主板上的 Reset 按钮以重新启动它。

该机器现在应该在您的 PC 上显示为 COM/串行端口，您应该能够通过 OpenPnP 访问它。如果没有，请再次按下板上的 Reset（重置）按钮，或在闪烁完成后重新启动设备。
